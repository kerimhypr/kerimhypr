## About

I'm mostly into web apps, backend stuff, realtime features, media tools and poking at web applications with Burp Suite.

I use Linux for basically everything. I also use AI a lot while building things, mostly for bouncing ideas around, debugging, refactoring and getting unstuck. Sometimes it writes something useful. Sometimes it confidently makes everything worse.

## AI, Apparently

I use AI pretty heavily while developing.

Not because I want a machine to magically build everything for me, but because having something to throw ideas at is ridiculously useful.

It helps with boilerplate, debugging, weird errors, refactors, documentation and the classic "why the fuck is this not working" moment.

The final code still has to survive my testing.
