## A bit about me

Mostly web apps, backend stuff, realtime features, media tools and random ideas that turn into projects.

I use Linux for basically everything. Burp Suite is probably the tool I know best when I'm poking at web applications.

I also use AI a lot while developing. It's great for bouncing ideas around, debugging and getting through boring parts. It also occasionally invents a completely new problem while fixing the old one.

## Things I've built

| Project | What it is |
| --- | --- |
| **[Akayroom](https://github.com/kerimhypr/akayroom)** | Realtime community app with Firebase, WebRTC and an experimental AI Twin system. |
| **[Soulweb](https://github.com/kerimhypr/soulweb)** | Web client for Soulseek-compatible backends such as slskd, with search, transfers and playback. |
| **[ytdlp-web](https://github.com/kerimhypr/ytdlp-web)** | Stateless media tooling built around yt-dlp and FFmpeg. |
| **[Droppoint](https://github.com/kerimhypr/Droppoint)** | Experimental local file-sharing project. |
