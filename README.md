## Me

Mostly web, backend, realtime stuff and whatever random idea sounds fun that week.

Linux is where I live while coding. Burp Suite is probably the tool I know best when it comes to poking at web applications.

And yes, I use AI a lot. It helps me think through ideas, write boring bits, debug things, and occasionally suggest something so stupid that it becomes funny.

## Projects

### Akayroom

Realtime community app built around Firebase and WebRTC, with an experimental AI Twin system.

`Next.js` `Firebase` `WebRTC` `Cerebras AI`

### Soulweb

A web client for Soulseek-compatible backends such as slskd. Search, transfers, player controls and a server-side gateway.

`Next.js` `React` `TypeScript` `PostgreSQL` `Zod`

### ytdlp-web

Stateless media tooling built around yt-dlp and FFmpeg.

`FastAPI` `Python` `yt-dlp` `FFmpeg` `Docker`

## AI is definitely involved

There isn't a dramatic story here. I use AI because it's useful.

Sometimes I'm writing code. Sometimes I'm asking a model why a perfectly reasonable line of code decided to ruin my evening.

It speeds things up, but I still test everything, especially with Burp Suite when I'm working on web stuff.

```text
me -> idea
   -> AI
   -> code
   -> Linux
   -> test
   -> break something
   -> fix it
   -> ship
```
